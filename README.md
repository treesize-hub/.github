## Tips and Tricks for Daily Use

- Start from the largest folders to get quick results with each review.
- Use treemap view to spot heavy branches at a glance.
- Apply date and size filters to narrow long file lists.
- Save frequent scan targets as favorites for faster repeat checks.
- Schedule automatic scans during quiet hours for fresh reports.
- Export to common formats to keep a clear history of changes.

## Quick Start Walkthrough

1. Open TreeSize Professional and select a drive or folder to review.
2. Run a fresh scan and wait for the folder tree to build.
3. Sort by size to highlight the largest locations first.
4. Open the chart view for a visual breakdown of usage.
5. Select unneeded items and move them or clear them with care.
6. Export the report for records or team review.
